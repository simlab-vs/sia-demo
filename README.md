# sia-demo

Teaching demos connecting BIM (IFC) with engineering workflows in Python. Each folder is a
self-contained uv project; run the commands from inside it.

| Demo | What it shows |
|---|---|
| [`ifc-fem-demo`](ifc-fem-demo) | A small house built as IFC4, turned into a finite element model (PyNite), with stress rendering and a seismic scenario against SIA 261 |
| [`points-to-bim`](points-to-bim) | Laser scans of the Pont de la Praz (A9, Ballaigues) turned into an IFC 4.3 bridge model, validated against the scans, georeferenced to LV95 and rendered over swissALTI3D terrain |
